Script that fetches the item textures for a specific minecraft version and outputs the entries for de.amin.bingo.game.board.BingoMaterial

In the index.js file in the Line 51 you can comment in and out the console logging of the items
And on the Line 52-55 it Downloads and saves the textures.

Comments are made using // code

Run `npm run start` in a terminal to start the download.
